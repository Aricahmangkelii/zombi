# 3D Zombie Shooter - Night Apocalypse 🧟‍♂️🔫

Game pertahanan 3D interaktif bertema serangan zombie malam hari. Dibangun menggunakan **Three.js** untuk grafik 3D dan **Web Audio API** untuk efek suara sintetis.

## 🎮 Cara Bermain (How to Play)

1. **Aturan Utama**:
   - Bertahan hidup selama **60 detik** dari gelombang zombie yang datang.
   - Jangan biarkan zombie melewati garis pertahanan belakang!

2. **Mode Permainan**:
   - **1 Player vs Horde**: Bermain sendiri membasmi zombie.
   - **2 Players (Co-op)**: Bermain bersama teman dalam satu layar untuk mempertahankan area bersama-sama.

3. **Level AI Zombie**:
   - **Easy**: Gerakan zombie lambat dan jumlah lebih sedikit.
   - **Medium**: Kecepatan standar.
   - **Hard**: Zombie bergerak sangat cepat dan spawns lebih gencar.

4. **Kontrol Karakter**:
   - **Pemain 1 (P1 - Biru)**:
     - Gerak: `W` (Maju), `A` (Kiri), `S` (Mundur), `D` (Kanan)
     - Tembak: `Spasi`
   - **Pemain 2 (P2 - Oranye)**:
     - Gerak: Tombol Panah (`Up`, `Left`, `Down`, `Right`)
     - Tembak: Tombol `Enter` / `Numpad 0`

## 🚀 Cara Menjalankan di GitHub Pages

1. Buat repositori baru di GitHub (misalnya: `zombie-shooter-3d`).
2. Unggah file `index.html` dan `README.md`.
3. Buka **Settings** repositori > **Pages**.
4. Pilih branch `main` (atau `master`) dan simpan (`Save`).
5. Kunjungi URL GitHub Pages yang disediakan untuk langsung memainkannya dari browser!
